💻 Mi Portfolio Personal - Paula Rodríguez

¡Bienvenido/a al repositorio de mi portfolio web! Este proyecto fue diseñado y desarrollado desde cero utilizando HTML5 y CSS3 con el objetivo de presentar mi perfil profesional, mis habilidades técnicas y los proyectos de software que he construido.

🚀 Vista Previa

🛠️ Tecnologías Utilizadas

HTML5: Estructura semántica y accesible.

CSS3: Diseño responsivo (CSS Grid y Flexbox), variables, gradientes, animaciones suaves (transition y transform) y paleta de colores oscura (Dark Mode).

Google Fonts: Tipografía Inter para una lectura limpia y moderna.

Font Awesome: Iconografía vectorial para enlaces y redes de contacto.

💻 Cómo ejecutarlo localmente

Si deseas clonar y probar este proyecto en tu computadora:

Clona este repositorio:

git clone https://github.com/rodriguezpaula97/Portfolio.git


Ingresa a la carpeta del proyecto:

cd Portfolio


Abre el archivo index.html directamente en tu navegador web favorito (o utiliza la extensión Live Server en Visual Studio Code).
